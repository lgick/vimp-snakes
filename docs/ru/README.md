# Документация VIMP Snakes

`vimp-snakes` — игра-плагин для [движка VIMP](https://github.com/lgick/vimp-engine)
— арена змеек «все против всех»: один бесконечный раунд на одной круглой
карте, змейки, которые никогда не останавливаются, и кристаллы, которые
одновременно и рост, и очки. Правила, симуляция и сущности рендеринга,
специфичные для этой игры, загружаются движком динамически в рантайме по
контракту плагина (`GameManifest`/`HostPlugin`/`ClientPlugin`).

За всем, что не специфично для этой игры — P2P-транспорт, мастер-сервер,
Worker-инфраструктура браузерного хоста, MVC/рендер-каркас клиента, общий
Rust-crate движка — см. доки самого движка:
[vimp-engine/docs/ru/](https://github.com/lgick/vimp-engine/blob/main/docs/ru/README.md).

## С чего начать

- **Хочу запустить матч локально** → [getting-started.md](getting-started.md)
- **Хочу понять игровые правила** → [gameplay.md](gameplay.md)

- **Хочу добавить контент** → [extending.md](extending.md)
- **Хочу понять, как это подключается к движку** → [architecture.md](architecture.md), затем движковый [plugin-api.md](https://github.com/lgick/vimp-engine/blob/main/docs/ru/plugin-api.md)
